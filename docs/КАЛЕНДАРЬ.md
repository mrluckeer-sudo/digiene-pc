# Техническое задание: Календарь

Проект: DigiGen PC (mrluckeer-sudo/digiene-pc)
Референс: Яндекс Календарь
Статус: на разработку. Первая версия собрана в приложении «Календарь».

## 1. Цель

Добавить в тренажёр приложение «Календарь» с базовой функциональностью корпоративного календаря. Календарь используется в учебных сценариях: приглашения на встречи могут быть частью фишинга, а напоминания — триггерами для действий игрока.

## 2. Функциональные требования

### 2.1. Отображение событий

Режимы просмотра:

- День — вертикальная сетка часов (08:00–20:00), события как блоки
- Неделя — 7 колонок, компактный вид событий
- Месяц — сетка дней, короткие названия событий

Навигация:

- Кнопки «←» / «→» для перехода между периодами
- Кнопка «Сегодня» для возврата к текущей дате
- Переключатель режимов (день / неделя / месяц)

### 2.2. Создание события

Поля формы: название (обязательное), дата и время начала, дата и время окончания или «весь день», место, описание, гости из справочника, напоминание (без напоминания, за 15 минут, за 1 час, за 1 день).

«Сохранить» добавляет событие в `state.events`. «Отмена» закрывает форму без сохранения.

### 2.3. Гости и приглашения

Гости добавляются по email с автодополнением из контактов. Статус гостя: ожидает / принял / отклонил. Входящее приглашение от NPC помечается «Приглашение» и имеет кнопки «Принять» / «Отклонить».

### 2.4. Напоминания

Плашка появляется, когда до начала осталось не больше выбранного срока и событие ещё не началось. Клик по плашке открывает это событие в календаре.

### 2.5. Редактирование и удаление

Клик по событию открывает карточку. «Редактировать» открывает форму с заполненными полями. «Удалить» убирает событие. Если у встречи есть гости, удаление просит нажать кнопку ещё раз.

## 3. Модель данных

`state.events` хранит события с полями `id`, `title`, `start`, `end`, `allDay`, `location`, `description`, `guests`, `reminder`, `isInvite`, `inviteStatus`.

Журнал действий — `state.eventLog`: `calendar_event_create`, `calendar_invite_accept`, `calendar_invite_decline`, `calendar_link_click`.

## 4. Сиды

- «Планёрка проектного офиса» — 21 ноября 2026, 10:00, гость Марина Котова.
- «Срок по счетам» — 21 ноября 2026, 16:30, без гостей.
- «Срочное совещание» — приглашение с ссылкой `https://nord-meet.example/urgent`. Время ставится на ближайшие минуты при первом запуске, чтобы напоминание можно было увидеть в этой сессии.

## 5. Ограничения первой версии

Нет повторяющихся событий, нескольких календарей, перетаскивания и синхронизации с внешними сервисами. Уведомления на почту не отправляются.
